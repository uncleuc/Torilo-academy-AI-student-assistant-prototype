## Course Overview

Torilo Academy's Frontend Web Development programme focuses on developing practical skills for building and optimising responsive web interfaces.

The programme introduces core frontend technologies and modern JavaScript-based development.

## Duration

The Frontend Web Development Mastery programme is listed as an 8-week training programme.

The academy also lists an 8-week Frontend Web Development NEST option.
