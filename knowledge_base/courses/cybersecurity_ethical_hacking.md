## Course Overview

Torilo Academy's Cybersecurity & Ethical Hacking programme is designed to develop practical knowledge and skills for understanding cybersecurity, identifying security weaknesses, responding to incidents, and applying ethical hacking techniques.

The programme covers cybersecurity fundamentals, operating systems, networking, network security, cryptography, web security, incident response, security operations, governance, risk and compliance, and penetration testing.

## Duration

The Cybersecurity + Ethical Hacking Mastery programme is listed as a 16-week training programme.

The academy also lists an 8-week Cybersecurity Mastery option and a 16-week Cybersecurity + Ethical Hacking + NEST option.

## Learning Formats

The programme offers:

- Physical learning
- Live online learning
- Hybrid learning

## Curriculum

### Level 1 — Introduction to Cybersecurity

Topics include:

- Cybersecurity principles
- CIA triad
- Cyberattack types
- Cybersecurity domains
- Cybersecurity roles and career paths

### Operating Systems

Students are introduced to:

- Windows
- Linux
- Useful Windows and Linux commands

### Networking Fundamentals

Topics include:

- OSI model
- TCP/IP model
- Subnetting
- IP addressing
- DHCP
- Common ports
- Introduction to packet sniffing using Wireshark

### Network Security

Topics include:

- Firewalls
- IDS/IPS
- Proxies
- VPNs
- Port scanning
- Network hardening

### Cryptography

Topics include:

- Symmetric encryption
- Asymmetric encryption
- Hashing
- Digital certificates
- SSL/TLS
- PKI

### Web Fundamentals and Security

Topics include:

- Web architecture
- Web vulnerabilities
- OWASP
- Honeypots
- Honeynets
- Packet fragmentation
- Protocol tunnelling
- Spoofing and masquerading
- Encrypted attacks

### Incident Response and Forensics

Topics include:

- Incident-response processes
- NIST incident-response concepts
- Incident types
- Playbooks
- Introduction to digital forensics
- Disk and memory forensics
- Autopsy
- FTK

### Security Policies and GRC

Topics include:

- Security policies
- Acceptable use
- Data handling
- Compliance
- HIPAA
- GDPR
- Introduction to Governance, Risk and Compliance

## Level 2 — SOC and Ethical Hacking

Topics include:

- Security Operations Centre structure
- Blue teams
- Red teams
- Ticketing tools
- Introduction to ethical hacking

## Threat Intelligence

Topics include:

- Threat-intelligence lifecycle
- Indicators of compromise
- Threat feeds
- OSINT tools

## Human Factor

Topics include:

- Social-engineering tactics
- Phishing simulations
- Insider threats
- User-training techniques

## Security Operations

Topics include:

- Investigation and triage
- Phishing investigation
- Malware investigation

## Penetration Testing

The programme includes penetration-testing content as part of its ethical-hacking curriculum.

## Artificial Intelligence

Students are also introduced to AI concepts and tools that can support productivity, automation, insight generation, and cybersecurity workflows.
