## Course Overview

Torilo Academy's Project Management programme develops practical skills for planning, executing, monitoring, controlling and closing projects.

The programme covers project-management methodologies, project planning, stakeholder management, risk management, project tools, software and AI.

## Duration

The Project Management Mastery programme is listed as an 8-week training programme.

## Learning Formats

The programme offers:

- Physical learning
- Live online learning
- Hybrid learning

## Curriculum

### Introduction to Project Management

Topics include:

- Project management fundamentals
- Project lifecycle
- Project-management processes
- Project stakeholders
- Stakeholder roles
- Project-management methodologies
- Waterfall
- Agile

### Project Initiation

Topics include:

- Project scope
- Project objectives
- Business cases
- Project charters
- Stakeholder identification
- Feasibility studies
- Risk assessment
- Project-team setup

### Project Planning

Topics include:

- Project plans
- Work Breakdown Structures

- Critical path
- Resource allocation
- Resource management
- Cost estimation

- Expectations

### Project Execution

Topics include:

- Project launch

- Communication

### Project Monitoring and Control

- Risk management

### Project Closure

Topics include:

- Project completion
- Handover

### Project Management Tools

The course introduces project-management software and tools including examples such as:

- Trello

- Project case studies
- Group project presentations

- Career paths in project management

### Artificial Intelligence

Students are introduced to AI concepts and tools that can:

- Generate insights
- Improve productivity
- Improve workflow efficiency
