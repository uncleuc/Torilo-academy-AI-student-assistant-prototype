## Course Overview

Torilo Academy's AI Engineering programme is designed to develop practical skills for building artificial intelligence systems and applying AI technologies to real-world problems.

The programme covers artificial intelligence concepts, machine learning, deep learning, natural language processing, generative AI, AI engineering tools, deployment, and end-to-end AI project development.

## Duration

The AI Engineering Mastery programme is listed as a 16-week training programme.

The course page also describes the programme as approximately four months of training.

## Learning Formats

The programme offers flexible learning options, including:

- Physical learning
- Live online learning
- Hybrid learning

## Course Curriculum

### 1. Python and Mathematics Refresher

Students learn Python and mathematical foundations relevant to machine learning.

Topics include:

- Python for Data Science
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Git and GitHub basics
- Linear algebra
- Probability
- Statistics
- Basic calculus

### 2. Core Machine Learning

The programme introduces core machine-learning concepts and techniques.

Topics include:

- Supervised learning
- Regression
- Classification
- Decision trees
- Support Vector Machines
- Unsupervised learning
- Clustering
- Principal Component Analysis

The course page also lists practical mini-projects including:

- Image classification
- Sentiment analysis using NLP

### 3. Neural Networks and Computer Vision

The programme includes neural-network and computer-vision concepts as part of the AI Engineering curriculum.

### 4. Natural Language Processing and Transformers

The curriculum includes Natural Language Processing and transformer-based technologies.

### 5. Generative AI

The Generative AI component includes:

- Generative AI concepts
- GANs and diffusion models
- Large Language Models
- LLM APIs
- Prompt engineering
- Retrieval-Augmented Generation (RAG)

### 6. AI Engineering Tools

Students are introduced to tools and practices used to build and deploy AI systems.

Topics include:

- MLOps fundamentals
- MLflow
- DVC
- Model deployment
- Flask
- FastAPI
- Docker
- Cloud AI platforms
- AWS SageMaker
- Google Cloud Vertex AI
- Hugging Face Spaces

The course page also lists practical projects including:

- Chatbot using a GPT API
- Image generator using GANs
- Machine-learning API using Docker

### 7. Capstone Build-Up

Students work toward an end-to-end AI project.

The course describes activities including:

- Selecting a real-world problem
- Gathering data
- Preprocessing data
- Training models
- Building an end-to-end AI system

Example problem areas mentioned include:

- Healthcare
- Fintech
- Edtech

### 8. Finalization and Portfolio

The final part of the programme focuses on preparing and presenting projects.

Activities include:

- Optimising and deploying projects to the cloud
- Publishing a GitHub repository
- Writing a technical blog or LinkedIn post
- Mock interviews
- Career coaching
- Presenting an AI solution at a Demo Day

## Artificial Intelligence Tools and Productivity

Throughout the programme, students are introduced to artificial intelligence concepts and tools that can improve productivity and workflow.

Students learn how AI can be used to:

- Automate tasks
- Gain insights
- Improve workflows
- Apply AI solutions to practical problems

## Practical Learning

The programme emphasises practical projects and application of AI concepts.

Students are expected to apply concepts through projects and progressively develop an AI portfolio.
