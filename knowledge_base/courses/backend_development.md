## Course Overview

Torilo Academy's Backend Development programme focuses on developing server-side applications and backend engineering skills.

The programme places particular emphasis on Python and Django, together with SQL and backend fundamentals.

## Duration

The Backend Web Development Mastery programme is listed as an 8-week training programme.

The academy also lists an 8-week Backend Web Development NEST option.
