## Course Overview

Torilo Academy's Product Design programme focuses on developing practical skills for designing digital products and user experiences.

The programme covers user research, user experience design, interface design, prototyping, design systems, usability, and product-design workflows.

## Duration

The Product Design Mastery programme is listed as an 8-week training programme.

The academy also lists a Product Design NEST option.

## Learning Formats

The programme offers:

- Physical learning
- Live online learning
- Hybrid learning

## Curriculum

### Introduction to Product Design

Topics include:

- Product design fundamentals
- Understanding users
- Understanding product problems
- Design thinking
- Product-development processes

### User Research

Students are introduced to methods for understanding users and identifying user needs.

Topics include:

- User research
- User interviews
- User personas
- User journeys
- Identifying user problems

### User Experience Design

Topics include:

- Information architecture
- User flows
- Wireframing
- Usability
- User-centred design

### User Interface Design

Topics include:

- Interface design
- Layout
- Typography
- Colour
- Components
- Visual hierarchy

### Prototyping

Students learn to create prototypes that communicate how a digital product should work.

### Design Systems

The programme introduces the principles of creating consistent reusable design components and systems.

### Practical Projects

Students apply product-design principles through practical projects and portfolio development.

## Artificial Intelligence

The course also introduces AI concepts and tools that can support productivity, automation, insight generation, and design workflows.
