## Course Overview

Torilo Academy's Data Analysis programme is designed to develop practical skills for collecting, cleaning, analysing, visualising, and interpreting data.

The programme focuses on tools and techniques used to transform data into useful insights for decision-making.

## Duration

The Data Analysis Mastery programme is listed as a 12-week training programme.

The academy also lists a Data Analysis Mastery + NEST option.

## Learning Formats

The programme offers flexible learning options including:

- Physical learning
- Live online learning
- Hybrid learning

## Course Curriculum

### 1. Data Foundations, Preparation and Cleaning

Students are introduced to fundamental concepts in data analytics.

Topics include:

- Data and data analysis concepts
- Data ecosystems
- Data collection
- Data organisation
- Data integrity
- Data-quality risks
- Data cleaning

Students also learn about the roles of spreadsheets, query languages, and data-visualisation tools in analytics.

### 2. Excel Foundations

Topics include:

- Excel interface
- Data entry
- Data editing
- Formatting
- Basic calculations
- SUM
- AVERAGE
- COUNT
- Charts
- Tables
- Conditional formatting

### 3. Excel Essentials

Topics include:

- Advanced formulas
- VLOOKUP
- INDEX/MATCH
- IF
- PivotTables
- Filtering
- Conditional formatting
- Data validation
- Error handling
- Excel best practices
- Productivity shortcuts

### 4. Power BI

Students learn how to use Power BI for data visualisation and reporting.

Topics include:

- Power BI interface
- Connecting to data sources
- Excel
- CSV
- SQL
- Reports
- Dashboards
- Charts
- Maps
- Slicers

Advanced Power BI topics include:

- Advanced visualisations
- KPIs
- Scatter plots
- Matrices
- Data modelling
- DAX
- Measures
- Calculated columns
- Performance optimisation

### 5. SQL

The programme introduces SQL and database querying.

Topics include:

- SQL fundamentals
- SQL Server
- MySQL
- SELECT
- FROM
- WHERE
- GROUP BY
- Filtering
- Sorting
- AND
- OR
- NOT
- IN
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN

### 6. Advanced Data Analysis

Advanced topics include:

- Subqueries
- Common Table Expressions
- Data manipulation
- INSERT
- UPDATE
- DELETE
- MERGE
- Integrating SQL with Excel
- Integrating SQL with Power BI
- ODBC
- OLE DB
- Data modelling
- Data mining
- Predictive analytics

## Artificial Intelligence

The programme also introduces artificial intelligence concepts and tools that can support data-analysis workflows.

Applications include:

- Automating tasks
- Gaining insights
- Improving productivity
- Applying AI to data-related workflows

## Statistics

The course information states that statistical analysis includes topics such as:

- Descriptive statistics
- Probability distributions
- Hypothesis testing
- Correlation analysis
- Regression models
- Inferential statistics

## Dashboards and Reporting

Data communication is a component of the programme.

Students learn to create dashboards and reports and communicate data insights to technical and non-technical audiences.

## Background Requirements

The public course information states that the programme is designed to be accessible to learners with limited technical backgrounds.

The course also references high-school-level mathematics and supplementary learning resources for relevant mathematical concepts.

## Practical Learning

The programme emphasises practical learning through projects and real-world data-analysis applications.
