## Course Overview

Torilo Academy's Cloud Computing programme develops practical knowledge and skills for working with cloud technologies, infrastructure, security, networking, databases, cloud architecture, migration, DevOps and cloud deployment.

## Duration

The Cloud Computing Mastery programme is listed as a 12-week training programme.
