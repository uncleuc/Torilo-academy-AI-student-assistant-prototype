## Course Overview

Torilo Academy's Full-Stack Software Development programme focuses on developing practical skills for building fully functional software applications.

The programme covers frontend development, backend development, databases, software-development practices, and AI concepts and tools.

## Duration

The Full-Stack Software Development Mastery programme is listed as a 16-week training programme.

The academy also lists a Full-Stack Software Development + NEST option.

## Learning Formats

The programme offers:

- Physical learning
- Live online learning
- Hybrid learning
